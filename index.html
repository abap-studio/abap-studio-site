How to install

ABAP Studio is the desktop app itself. It talks to your SAP system through sap-mcp, a small companion server that runs locally on your machine and connects using your own SAP credentials — nothing about your code or data passes through us.

Prefer slides? Download the PDF overview.

  1. Install Node.js

    Download and install Node.js 20.12 or later from nodejs.org if you don't already have it. This is what runs the sap-mcp server — a one-time setup step.

  2. Download sap-mcp

    Get it from github.com/abap-studio/sap-mcp (click Code → Download ZIP, or clone it) and extract it to %USERPROFILE%\sap-mcp — ABAP Studio looks there by default.

  3. Install its dependencies

    Open a terminal in the extracted sap-mcp folder and run npm install. You only need to do this once.

  4. Add your SAP connection details

    Copy .env.example to .env in that same folder, then fill in your SAP system's host, client, username and password. This file stays on your machine and is never uploaded anywhere.

  5. Download and install ABAP Studio

    After checkout (trial or paid), download ABAP-Studio-2.4.0-setup.exe from your order confirmation email or the My Orders page, and run the installer — a one-time step, after which every launch starts instantly. On first launch you'll be asked for a license key; click "Start a free trial" to get one instantly by email at no cost, or enter a purchased key. Then connect a Claude Code subscription or AWS Bedrock credentials in Settings.
